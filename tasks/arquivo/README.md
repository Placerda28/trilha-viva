# Arquivo de frentes concluídas

Aqui fica o texto integral de cada frente de trabalho, sem edição, como estava no `tasks/todo.md` até 18/10/2026. Cada arquivo leva a data de início da frente no nome.

- `AAAA-MM-DD-tema.md`: diário da frente (plano, provas, medições, decisões).
- `spec-*.md`: as especificações e contratos daquela frente. Quando um texto antigo cita `tasks/X.md`, o arquivo agora é `tasks/arquivo/spec-X.md`.

O que ainda está aberto fica em `tasks/todo.md`. O resumo de tudo o que foi feito, em uma linha por entrega, fica no `HISTORICO.md` do Drive.
